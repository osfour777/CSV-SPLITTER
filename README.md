# ✅ Hacker-Style CSV Splitter GUI 

A fast and stylish CSV splitter with a hacker-themed GUI, designed for ultra-large files (1M+ rows) with advanced features and multi-threaded performance. Perfect for data enthusiasts and developers who want speed with style.  

---

## Features

- ✅ Drag & Drop CSV files  
- ✅ Split by row count  
- ✅ Split by file size (MB)  
- ✅ Split into X equal parts  
- ✅ Parallel processing (multi-threaded)  
- ✅ Progress bar to monitor operations  
- ✅ Option to keep or remove the header  
- ✅ Select output folder  
- ✅ Ultra-fast chunked reading (handles 1M+ rows efficiently)  
- ✅ Hacker Green Theme with **Osfour Pakistan Pride** branding
